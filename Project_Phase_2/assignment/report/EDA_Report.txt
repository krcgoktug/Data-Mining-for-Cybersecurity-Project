The dataset exhibits a highly imbalanced class distribution. As shown in Figure X, the majority of the traffic belongs to label 0 (Benign) with 2,271,320 samples, while several attack categories contain only a few thousand samples. For example, label 4 contains 230,124 samples, whereas some attack classes such as labels 11, 6, and 5 have fewer than 6,000 samples.

This strong imbalance indicates that the dataset is dominated by normal traffic, which may bias machine learning models toward predicting the majority class. Therefore, model evaluation must carefully consider imbalance-aware metrics rather than relying solely on overall accuracy.

2. Feature Distribution Analysis
--------------------------------------------------

(INSERT FIGURE 2 HERE)

Figure X illustrates the distributions of the selected nine features used in the modeling phase. Most features exhibit heavily right-skewed distributions, where a large proportion of samples are concentrated near zero, while a small number of observations take extremely high values. This behavior is particularly evident for features such as Flow Duration, Total Packet Counts, and Flow Bytes/s.

Such skewness is common in network traffic data and reflects the presence of both short-lived benign flows and long-lasting or high-volume attack-related flows. The observed distributions justify the application of feature scaling and normalization techniques in the modeling stage, while emphasizing the importance of using the cleaned (non-scaled) data for exploratory analysis.
